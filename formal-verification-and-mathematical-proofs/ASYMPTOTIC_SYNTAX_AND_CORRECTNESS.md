# An explicit polynomial-size family extending SG-DIFRA syntax

**Status:** syntactic/correctness extension only. This is not a security reduction.

For every positive integer security parameter \(\lambda\) divisible by 4 and at least 16, define:
\[
M=2\lambda,\quad m=8\lambda,\quad u=\lambda/2,\quad
N=5\lambda,\quad n=\lambda/2,\quad (k,d,r)=(5,3,2).
\]
Keep the noise rate \(\nu=3/16\), \(T_{\mathrm{rep}}=7\), message length \(\ell=\lceil5\lambda/2\rceil\), and bucket size \(B=3^3=27\). Unlike the original fixed-field proposal, choose:
\[
h(\lambda)=\max(10,\lceil\log_2(2\lambda)\rceil),\qquad
K_\lambda=\mathbb F_{2^{h(\lambda)}}.
\]

### Proposition A — all operations have polynomial description and runtime

There are enough field elements for \(M\) pairwise distinct GRS evaluation points: \(2^{h(\lambda)}\ge2\lambda=M\). The total number of public labels is \(q=mB=216\lambda\). Each label has \(N=5\lambda\) symbols of \(h(\lambda)=O(\log\lambda)\) bits, so dense public labels occupy \(O(\lambda^2\log\lambda)\) bits. The ternary local table has \(3^d=27\) entries per predicate and \(k=5\) is constant, so it can be generated and enumerated in polynomial time. Random full-rank matrices can be generated by rejection with expected polynomial work over the field. Standard exact finite-field arithmetic, polynomial factorization to obtain irreducible moduli, and Reed–Solomon unique decoding admit polynomial algorithms.

This resolves the **fixed-\(GF(1024)\) length cap** at the level of syntax. It is intentionally **not** an extension of SGD-R2/SGD-R3's varying local dimensions; it keeps the mathematically simple R1 local geometry at every size.

### Proposition B — finite-channel correctness vanishes exponentially

The planted \([M,u,M-u+1]_{|K_\lambda|}\) code corrects up to \(t=\lfloor(M-u)/2\rfloor=3\lambda/4\) errors (when \(\lambda\) is a multiple of four). The bit-zero failure probability obeys
\[
p_0\le\Pr[\mathrm{Bin}(2\lambda,3/16)>3\lambda/4]
\le \exp[-2\lambda D(3/8\,\Vert\,3/16)],
\]
where \(D(x\Vert y)=x\ln(x/y)+(1-x)\ln((1-x)/(1-y))>0\). This is the standard Chernoff bound applied at fraction \(t/M=3/8>\nu\).

A uniform bit-one ciphertext is accepted with probability at most
\[
p_1\le |K_\lambda|^{u-M}
\sum_{j=0}^{3\lambda/4}\binom{2\lambda}{j}(|K_\lambda|-1)^j.
\]
Bounding the sum by \((2\lambda+1)2^{2\lambda}|K_\lambda|^{3\lambda/4}\) yields
\[
p_1\le(2\lambda+1)2^{2\lambda}|K_\lambda|^{-3\lambda/4}
=2^{-\Omega(\lambda\log\lambda)}.
\]
Therefore the idealized bit and whole-message failure probabilities are negligible in \(\lambda\), even with a polynomial number of repetitions. This proof establishes **correctness for ideal algorithms**, not semantic security.

### Missing security theorem

For this growing field, two new assumptions would have to be stated and evaluated over the *actual* uniform ensemble families: MDS-HBCE and \(2^{h(\lambda)}\)-ary LPN. No current result proves that they are hard for polynomial-time classical or quantum algorithms. The independence-projection theorem still applies, so NCSG is not the security basis of this family. A successful correctness proof cannot be promoted to IND-CPA or IND-CCA security.

### What the fixed three profiles mean

SGD-R1/R2/R3 remain finite research benchmarks; their nominal labels 128/192/256 do not become certified classical or quantum security levels merely because an asymptotic **syntax** can be written. The exact original finite-field tables and regression code remain unchanged.
